# さんすうプリントメーカー

たし算・ひき算・かけ算・わり算の計算プリントを、ブラウザだけで作って印刷できるWebツールです。
インストール・登録は不要で、PCでもスマホでも使えます。

`multiplication/`（PyQt5 製の九九プリント作成アプリ）を、だれでも使えるWebツールとして作り直したものです。

## できること

| 項目 | 内容 |
| --- | --- |
| 計算の種類 | たし算・ひき算・かけ算・わり算（複数えらぶと、まぜて出題） |
| たし算 | 1けた+1けた 〜 3けた+3けた／くり上がり あり・なし |
| ひき算 | 10までの数−1けた 〜 3けた−3けた／くり下がり あり・なし（答えは0以上） |
| かけ算 | 九九（段を指定、段のじゅんばんに並べることも可）／2けた×1けた・3けた×1けた・2けた×2けた |
| わり算 | 九九のぎゃく（わる数の段を指定）／2けた÷1けた 〜 3けた÷2けた／あまり なし・あり・まぜる |
| 虫食い算 | 空らんを「こたえ」「式の中（□×3=12）」「まぜる」から選択 |
| レイアウト | 1まいの問題数（〜100）、まい数（〜20）、列数、文字の大きさ、ならび順（たて／よこ） |
| ヘッダー | タイトル、なまえ・日付・タイム・点数欄、問題番号の表示切りかえ |
| 解答ページ | 答えを赤字で入れたページを、問題ページのあとに出力 |
| 共有 | 設定と問題は URL に保存されるので、リンクを送れば同じプリントを再現できる |

- 出せる問題が足りるあいだは、同じ問題をくり返しません（九九なら81問まで重複なし）。
- 列数「自動」では、文字がいちばん大きく読みやすくなる列数を選びます。
- 入力した設定はブラウザの中だけで使われ、サーバーには送信されません。

## 使い方

1. 計算の種類と範囲をえらぶ
2. 問題数・レイアウトを調整する（右側のプレビューにすぐ反映されます）
3. 「印刷 / PDFで保存」をおす
   - PDFにしたいときは、印刷画面で保存先を「PDFに保存」にします
   - 用紙はA4、倍率は100%がおすすめです

## ローカルで動かす

ビルドは不要です。ES Modules を使っているので、ファイルを直接開くのではなく簡単なHTTPサーバーで配信してください。

```bash
cd arithmetic-worksheet
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## テスト

問題生成ロジック（`js/generator.js`）のテストを Node.js 標準のテストランナーで実行します（Node.js 20 以上）。

```bash
cd arithmetic-worksheet
npm test
```

## 公開（GitHub Pages）

`.github/workflows/arithmetic-worksheet.yml` で、`master` ブランチに反映されると自動でテスト → GitHub Pages へ公開します。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` になります。

## ファイル構成

```
arithmetic-worksheet/
├── index.html          # 画面
├── style.css           # 画面・印刷用スタイル（A4）
├── js/
│   ├── generator.js    # 問題生成（DOM非依存・シード付き乱数）
│   ├── render.js       # プリントの描画・レイアウト計算
│   └── app.js          # フォーム・URL共有・印刷
├── tests/
│   └── generator.test.mjs
├── package.json        # テスト実行用（依存パッケージなし）
└── LICENSE
```
